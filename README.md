# 🏗 Basokodi Trading (PTY) LTD Website

A professional industrial company website developed for Basokodi Trading (PTY) LTD.

---

## 📖 About

This project is focused on creating a modern, responsive and corporate website that represents Basokodi Trading's engineering services, industrial supplies and construction expertise.

The website is being built using only HTML, CSS and JavaScript.

---

## 🚀 Current Features

- Modern Hero Section
- Responsive Navigation
- Hero Image Slider
- WhatsApp Contact Button
- Glassmorphism Design
- Industrial Theme

---

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
